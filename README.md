No início, foi criado um menu, personalizado com cores e botões clicáveis, contendo os três itens principais para a organização dos dados. Os itens presente no menu constavam com três opções de navegação: Titular; informes e Notas. 

No campo TITULAR, criamos e formatamos uma tabela para preenchimento com os dados da pessoa titular da declaração de renda. 

No campo INFORMES, criei uma área para o usuário informar até cinco bancos. A área lista automaticamente os principais bancos utilizados e mostra a soma total do saldo de todos os bancos. Na parte descrita como ANEXO, o usuário envia o PDF que comprove o extrato bancário.

No campo NOTAS, criei uma área especifica de entrada de cada tipo de renda. O usuário pode informar a data, a categoria especifica e, por fim, o valor.
